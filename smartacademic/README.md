# 📌 Project Overview

**Smart Academic Feedback System** is a role-based academic feedback and analytics platform designed for educational institutions to collect, manage, analyze, and export student feedback efficiently.

The system supports:

✅ Dynamic Feedback Forms  
✅ Public & Private Feedback Collection  
✅ Anonymous & Identified Responses  
✅ Role-Based Authentication  
✅ Analytics Dashboard  
✅ PDF & Excel Report Generation  
✅ QR-Based Feedback Access  
✅ Student Upload Through Excel

The platform is designed to simplify academic feedback management for **Admins, Teachers, and Students**.
